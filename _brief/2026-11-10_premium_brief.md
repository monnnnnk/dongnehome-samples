# 재영님 디자인 지시 (2026-11-10 11:33, 원문 그대로)

현재 웹페이지의 디자인이 지나치게 촌스럽고 완성도가 낮습니다.
단순히 색상이나 폰트를 바꾸는 수준의 수정이 아니라, 디자인의 미적 수준 자체를 끌어올려 주세요.

1. 디자인 방향
- 글로벌 IT 기업의 프리미엄 웹서비스 수준
- 세련되고 현대적인 미니멀리즘
- 절제된 고급스러움과 정돈된 레이아웃
- 유치하거나 과장된 장식 금지
- AI가 흔히 만드는 전형적인 템플릿 디자인 탈피

2. 절대 금지
- 의미 없이 둥근 모서리를 남발하는 디자인
- 과도한 그라데이션과 형광색
- 불필요한 그림자와 테두리
- 촌스러운 아이콘과 일러스트
- 카드만 무한 반복하는 레이아웃
- 과도한 여백 또는 답답한 정보 배치
- 색상 여러 개를 무분별하게 사용하는 것

3. 디자인 완성도
- 타이포그래피의 크기, 굵기, 간격을 정교하게 설계
- 여백과 정렬에 일관된 디자인 시스템 적용
- 색상은 2~3가지 중심으로 절제
- 시각적 위계가 명확해야 함
- 버튼, 메뉴, 입력창 등 모든 요소의 디자인 통일
- 모바일과 PC 모두 완성도 있게 구현

4. 디자인 레퍼런스
Apple, Linear, Stripe, Vercel, Raycast 등. 베끼지 말고 타이포그래피, 레이아웃, 정보 구조, 디테일의 완성도를 분석해 적용.

5. 작업 방식
1) 현재 디자인 문제점 분석 2) 수준 높은 실제 사이트 레퍼런스 조사 3) 디자인 시스템 먼저 정의 4) 전체 페이지를 일관된 방향으로 재설계 5) PC·모바일 직접 확인 6) 어색한 부분 반복 수정

중요: 기능 구현 ≠ 디자인 완성. 전문 프로덕트 디자이너 관점으로 판단. 실제 상용 서비스로 출시해도 부끄럽지 않은 수준.
